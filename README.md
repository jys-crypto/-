秒合约交易所可以控制输赢
## 交易控制功能

- **输赢控制**：全局胜率设置（0-100%），可开关
- **单用户控制**：为单个用户设置专属胜率，优先于全局
- **杠杆功能**：可开关，支持 1x/2x/5x/10x/25x/50x/100x
- **交易时长**：可设置默认秒数，单用户可额外增加
- **手动结算**：后台"交易控制"页面可手动结算待结算订单

## 代理管理功能（代理管理 → 代理列表）

- **代理维护**：添加 / 编辑（用户名、邮箱、佣金比例）/ 冻结解冻
- **修改代理密码**：列表每行「改密」按钮（编辑弹窗内也有入口），支持
  - 新密码 + 确认密码，至少 6 位、最多 50 位
  - 「生成随机密码」（12 位随机串，自动回填并明文显示）
  - 「显示密码」开关与实时密码强度提示（弱/中/强）
  - 修改后写入 SHA-256 哈希与修改时间，并记录后台操作日志
- **生效方式**：总后台的代理列表是代理登录凭据的唯一来源。代理后台（`/agent-backend/`）登录时会读取总后台维护的代理账号进行邮箱 + 密码校验，因此在总后台改密后，代理使用新密码即可登录；账号被冻结的代理无法登录
